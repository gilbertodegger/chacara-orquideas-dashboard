# Chácara das Orquídeas — Dashboard Leiteiro

Versão online 3.0 do dashboard da Chácara das Orquídeas.

## Privacidade dos dados

O repositório contém somente a aplicação. Dados de DairyComp/DC305, genética, ACW, alimentação, qualidade, financeiro e demais importações não devem ser versionados aqui. A aplicação foi preparada para iniciar sem base embutida e armazenar as importações localmente no navegador.
