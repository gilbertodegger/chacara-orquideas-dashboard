# Synapse — Chácara das Orquídeas

Versão 4.0 do dashboard leiteiro da Chácara das Orquídeas, com navegação por guias e subguias, importação de planilhas e exportação em PDF.

## Privacidade dos dados

O repositório contém somente a aplicação. Dados de DairyComp/DC305, genética, ACW, alimentação, qualidade, financeiro e demais importações não devem ser versionados aqui. A aplicação inicia sem base embutida e armazena as importações localmente no navegador.
